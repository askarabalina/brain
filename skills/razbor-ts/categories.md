# Канонические требования

Накопительный список. Каждое требование здесь — один `id` и одна формулировка,
к которым приводятся разные варианты из разных ТС.

Файл растёт по мере разбора. Новое требование → следующий свободный номер
в своём разделе. **Существующие `id` не переименовывать и не переиспользовать:**
на них ссылаются уже разобранные закупки.

Разделы по префиксам: `EP` рабочие места, `NW` сеть, `DT` обнаружение,
`IN` расследование, `AD` администрирование, `IT` интеграции, `CM` соответствие.
