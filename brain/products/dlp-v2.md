# Функционал DLP v.2 (CyberGuard)

Что продукт умеет на сегодня. Отвечает на вопрос «а у нас есть X» — в разговоре
с заказчиком, при разборе ТС закупки, при планировании доработок.

**Это не роадмап и не список задач.** Задачи в Execution Hub, причины решений
в `projects/dlp-v2.md`. Здесь только состояние возможностей.

## Статусы

| Статус | Что значит |
|---|---|
| `есть` | работает в выпущенной версии, можно показывать и обещать |
| `частично` | работает с оговоркой — оговорка обязательна в примечании |
| `в работе` | делается сейчас, срок в Hub |
| `план` | решено делать, ещё не начато |
| `нет` | не делаем или не решено |
| `уточнить` | **значение по умолчанию**, пока не подтверждено |

Идентификаторы — общие с `skills/razbor-ts/categories.md`. Благодаря этому
разбор ТС закупки подставляет колонку покрытия отсюда, а не спрашивает заново.
