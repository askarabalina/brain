# Телеграм

Бот над той же базой знаний. Нужен, чтобы спрашивать с телефона и диктовать
заметки голосом, когда ноутбук закрыт.

Работает на [nanobot](https://github.com/HKUDS/nanobot) — он даёт канал
телеграма, расшифровку голосовых, белый список и расписание из коробки.
Своего кода тут нет, только конфиг.

## Главное: с телефона только чтение

Телеграм подключается к Execution Hub **без инструментов записи**. Не правилом
в промпте, а списком `enabledTools`: незарегистрированный инструмент модель
вызвать не может, как бы её ни просили.

```
MCP: registered tool 'mcp_brain_whoami'
MCP: skipping tool 'mcp_brain_get_reference' (not in enabledTools)
```

Что доступно с телефона:

| | Телеграм | Компьютер |
|---|---|---|
| Задачи Hub: читать | да | да |
| Задачи Hub: писать комментарии, менять статусы | **нет** | да |
| База знаний: читать | да | да |
| База знаний: заметка (`save_note`) | да | да |
| Справочник личных данных | **нет** | да |

Заметка разрешена намеренно: продиктовать «решили переводить BOX на Ubuntu,
потому что лицензии» по дороге — ровно то, ради чего бот и нужен. Запись идёт
в git на машине, где он запущен, так что её видно и можно откатить.

Справочник (ИИН, серийные номера) с телефона закрыт: переписка уходит
на серверы телеграма, и личным данным там не место.

## Что нужно

**1. Бот.** [@BotFather](https://t.me/BotFather) → `/newbot` → токен.

**2. Свой Telegram ID.** [@userinfobot](https://t.me/userinfobot) пришлёт число.
Без белого списка бот ответит кому угодно.

**3. Ключ модели.** Тут важное: **подписка Claude Max не даёт доступа к API.**
Это разные вещи, и nanobot умеет только API-ключ.

Варианты:

| Вариант | Что нужно |
|---|---|
| Anthropic API | ключ в [console.anthropic.com](https://console.anthropic.com), оплата по токенам, отдельно от подписки |
| Google Gemini | ключ в Google AI Studio, есть бесплатный уровень |
| Уже имеющийся OAuth | `nanobot provider login github-copilot` или `xai-grok`, если такие подписки есть |

Расход на бота небольшой: утренняя сводка и несколько вопросов в день — это
единицы долларов в месяц. Поставь месячный лимит в консоли провайдера.

**4. Доступ к Execution Hub.** Тот, что работает в Claude Code, идёт через
коннектор claude.ai — nanobot им пользоваться не может. Нужен прямой адрес
MCP-сервера и токен, их выдаёт администратор Execution Hub.

Если его пока нет, бот всё равно полезен: база знаний, проекты, продукты
и заметки работают без Hub. Задачи добавятся, когда появится доступ.

**5. Распознавание речи** — для голосовых. Ключ любого сервиса, который
поддерживает nanobot.

## Установка

```bash
# nanobot, если ещё не стоит
git clone https://github.com/askarabalina/project.git nanobot
cd nanobot && python3 -m venv .venv && source .venv/bin/activate && pip install -e .

# конфиг
mkdir -p ~/.nanobot
cp ПУТЬ/К/brain/telegram/config.example.json ~/.nanobot/config.json
```

В конфиге замени `ПУТЬ/К/brain` на настоящий путь — в двух местах, `command`
и `BRAIN_DIR`.

Секреты в конфиг **не вписывай**: они подставляются из переменных окружения
через `${ИМЯ}`. Положи их в `~/.nanobot/env` и подгружай перед запуском:

```bash
export ANTHROPIC_API_KEY=...
export TELEGRAM_BOT_TOKEN=...
export TELEGRAM_USER_ID=...
export EXECUTION_HUB_MCP_URL=...
export EXECUTION_HUB_TOKEN=...
export TRANSCRIPTION_API_KEY=...
```

```bash
chmod 600 ~/.nanobot/env
```

Запуск:

```bash
source ~/.nanobot/env
nanobot gateway
```

Проверка — напиши боту:

> что ты про меня знаешь

Должен ответить из `profile.md`. Потом:

> что у меня горит

## Утренняя сводка

Когда бот заработает, попроси его прямо в телеграме:

> каждый будний день в 8:30 присылай сводку: сначала блокеры с числом дней
> молчания, потом просрочки, потом сроки на сегодня

Он заведёт себе расписание через инструмент `cron`.

**Но:** сводка придёт, только если бот в этот момент запущен. На ноутбуке это
значит «если он включён и не спит» — то есть в 8:30 скорее всего нет.

Для настоящей утренней сводки нужна машина, которая не выключается: виртуалка
за пару тысяч тенге в месяц. Конфиг там тот же, переносится копированием папки.

До этого бот работает как «спросить с телефона, пока ноутбук включён» — это
тоже полезно, просто не автоматически.

## Безопасность

- Переписка с ботом уходит на серверы телеграма. Для рабочих вопросов
  по проектам это обычно приемлемо, для данных под NDA — нет. Раздел
  «Границы» в `profile.md` действует и здесь.
- Белый список обязателен: без `allow_from` бот отвечает любому, кто найдёт
  его по имени.
- Токен бота — секрет. Утёк — отзови через BotFather и выпусти новый.
- Запись в Execution Hub и справочник личных данных закрыты списком
  `enabledTools`. Не убирай их оттуда «на время», чтобы что-то быстро
  поправить с телефона: правка в Hub без просмотра черновика — ровно то,
  от чего эта настройка защищает.
